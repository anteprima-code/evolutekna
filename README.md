# Evolutekna Holding — landing page

Sito statico: nessuna build, nessuna dipendenza da installare.

## Struttura
- `index.html` — pagina
- `styles.css` — stili (desktop 1280px identico al Figma + breakpoint 1279 / 1023 / 767)
- `assets/` — immagini, loghi, icone e decorazioni SVG estratte dal file Figma

## Pubblicazione
Caricare il contenuto della cartella nella root del dominio (o in una sottocartella).
Funziona su qualsiasi hosting statico: Apache, Nginx, GitHub Pages, Cloudflare Pages, Netlify.
